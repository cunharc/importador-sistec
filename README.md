# Importador de Plano de Contas — Implantação SISTEC

Ferramenta desktop para importar Plano de Contas de planilhas Excel (.xlsx) diretamente para o banco de dados Firebird da SISTEC (TABELA_PLANO).

## Pré-requisitos
- Python 3.8 ou superior instalado.
- Biblioteca do Firebird Client (`fbclient.dll`) disponível na máquina.

## Instalação
1. Abra o terminal na pasta do projeto.
2. Instale as dependências executando:
   ```bash
   pip install -r requirements.txt
